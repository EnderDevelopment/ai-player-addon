# AI Player Addon

The AI Player Addon is a Minecraft plugin designed to create an autonomous player that can mine blocks, build structures, fight mobs, and explore the world. This plugin is compatible with Minecraft Pocket Edition (PE) version 1.26.30 and uses the Paper API for enhanced functionality.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Start or restart your Minecraft server.

## Use

1. Once the server is running, use the command `/ciao` to interact with the AI player.
